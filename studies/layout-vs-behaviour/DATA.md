# Data not stored in git

Exclusions are also listed in the repository's `.gitignore`.

- **Sampled training states** (`experiments/train/*/states.npy`, about 3.1 GB). These are up to 300,000 observations
  per policy, drawn early in training. They are used for camouflage hold-out checks and for legibility correlations.
  They can be regenerated by retraining, but training is stochastic, so new
  samples will differ. `occupancy_never_on.npy`, the whole-training record of unused inputs, is in git and is what
  current camouflage builds use.
- **All model output**: replies, with-Python transcripts, call records, event streams, blind-coding packets and
  the scores built from them.
- **Round 1–2 material built from the post's released Pong network** (`astra/`, top-level `prompts/`,
  `released_pong_*`, `compare.*`). These are derived from third-party weights and are not redistributed.
  `external/fetch_upstream.sh` fetches the released networks.
- **Development scratch** (`work_*`, `normal_s0_*`) and backups (`*.bak*`).
- **Logs** (`*.log`).
- **The study's round-by-round notebook.**
